# هديتي لك ❤️ — تجربة حب رقمية سينمائية ثلاثية الأبعاد

منصة ويب متكاملة تتيح للمستخدمين صناعة تجارب حب رقمية خاصة (`Digital Love Experience`) ونقلها إلى أحبائهم عبر روابط خاصة ومشفرة.

---

## 🌟 المميزات الرئيسية

1. **مشهد ثلاثي الأبعاد تفاعلي وسينمائي (`Three.js / React Three Fiber`)**:
   - قلب زجاجي نابض بتقنية `MeshPhysicalMaterial`.
   - جزيئات ضوئية متلألئة وبتلات ورد متطايرة.
   - دعم كامل لتكيف الرسوميات على الأجهزة الضعيفة والجوال تلقائياً.

2. **معالج صناعة الهدية المكتمل (10 خطوات تفاعلية)**:
   - **الخطوة 1: من أنت؟**: تحديد اسمك، اسم شريكك، وطبيعة العلاقة لتخصيص التجربة.
   - **الخطوة 2: بداية القصة**: عداد حي بالسنوات، الأشهر، الأيام، الساعات، والدقائق.
   - **الخطوة 3: رسالة الحب**: محرر نصوص رومانسي مزود بمساعد كتابة ذكي متعدد الأساليب (`AI Romantic Scribe`).
   - **الخطوة 4: ذكرياتنا**: رفع الصور، إضافة التواريخ والقصص، وعرض ثلاثي الأبعاد بأنماط (Polaroid, Floating, 3D Wall, Cards).
   - **الخطوة 5: أغنيتنا**: مشغل صوتي أنيق، مقطوعات رومانسية جاهزة، وإمكانية رفع ملفك الصوتي الخاص.
   - **الخطوة 6: الفيديو**: إمكانية إضافة رسالة فيديو شخصية قصيرة.
   - **الخطوة 7: أشياء أحبها فيك**: بطاقات صفات متحركة وتفاعلية.
   - **الخطوة 8: اختيار القالب**: 8 قوالب ملهمة تغير الألوان والإضاءة والمشهد ثلاثي الأبعاد.
   - **الخطوة 9: الخصوصية**: حماية الهدية بكلمة سر، وجدولة موعد فتح الهدية مع عد تنازلي.
   - **الخطوة 10: المشاركة**: رابط سري عشوائي مشفر، رمز `QR Code` رومانسي مخصص، ومشاركة سريعة عبر واتساب وتيليجرام.

3. **تجربة المستلم السينمائية**:
   - شاشة سوداء غامضة لكشف المشاعر بالتدريج.
   - فك حظر الصوت في المتصفحات تلقائياً بنقرة زر الفتح.
   - تتابع المشاهد مع التمرير (`Scroll-driven story`).
   - مشهد ختامي عاطفي تتوج فيه أسماء الحبيبين مع ألعاب نارية وورود.

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm run start
```

افتح المتصفح على: `http://localhost:3000`
